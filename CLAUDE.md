# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Commands

Use **pnpm** (not yarn or npm) as the package manager.

```bash
pnpm start          # Start dev server at http://localhost:3000/claude-doc/
pnpm build          # Build static site into build/
pnpm serve          # Serve the built site locally
pnpm clear          # Clear Docusaurus cache (use when builds behave unexpectedly)
pnpm typecheck      # TypeScript type check
```

## Architecture

This is a **Docusaurus 3.9.2** documentation site for Claude Code, written primarily in Chinese (default locale `zh`) with English translation (`en`).

### Content Structure

- `docs/claude-code/` — main documentation, organized into subdirectories
- `_category_.json` files control sidebar labels, ordering (`position`), and collapse behavior
- Sidebar is **auto-generated** from the filesystem (`sidebars.ts` uses `autogenerated`)
- `docs/plans/` — internal planning documents (not part of the published docs nav)

### i18n

- Default locale: `zh` (Chinese), served at `/claude-doc/`
- English translations: `i18n/en/docusaurus-plugin-content-docs/current/`
- UI strings: `i18n/{locale}/code.json` and `i18n/{locale}/docusaurus-theme-classic/`

### Custom UI

- `src/pages/index.tsx` — homepage
- `src/components/HomepageFeatures/` — homepage feature cards
- `src/css/custom.css` — global CSS overrides

### Config Files

- `docusaurus.config.ts` — site config, navbar, footer, Mermaid support
- `sidebars.ts` — sidebar config (currently auto-generated, no manual overrides)

## MDX Gotcha

MDX parses `<` as JSX tag openers. In markdown tables or prose, always escape bare `<` characters:

```
<!-- Wrong -->
| 遗漏率 | <5% |

<!-- Correct -->
| 遗漏率 | &lt;5% |
```

This applies to any `<number`, `<variable`, or similar patterns not intended as JSX.
