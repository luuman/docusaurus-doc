### 条件语句

```
let number = 3;
if number < 5 {
    println!("条件为 true");
} else {
    println!("条件为 false");
}
```

和swift一致，小括号可以省略，{}必须存在

```
if number { // error[E0308]: mismatched types
    println!("true");
}
```

这里和swift一致，都只能用bool表达式，其他方式会报错



### for循环

```
// for循环遍历
let a = [10, 20, 20, 30, 50];
for i in 0..a.len() { // 0-len 
    print!("{} ", a[i]);
}
println!("");
for i in a {
    print!("{} ", i);
}
println!("");
for i in a {
    print!("{} ", i);
}
println!("");
for i in a.iter() { // 不可变引用
    print !("{} ", i);
}
println!("");

// for修改元素
let mut a = [String::from("A"), String::from("B")];
for i in 0..a.len() {
    a[i] = String::from("C");
}
println!("{:?}", a);
for value in a.iter_mut() {
    (*value) = String::from("D");
}
println!("{:?}", a);

// for遍历同时获取index
for (_idx, _val) in a.iter().enumerate() {

}
```

我们看到有for循环直接遍历集合，还有通过iter()遍历集合, 还有通过iter_mut()方式的遍历，他们只是所有权不同

| 使用方法                      | 等价使用方式                                      | 所有权     |
| ----------------------------- | ------------------------------------------------- | ---------- |
| `for item in collection`      | `for item in IntoIterator::into_iter(collection)` | 转移所有权 |
| `for item in &collection`     | `for item in collection.iter()`                   | 不可变借用 |
| `for item in &mut collection` | `for item in collection.iter_mut()`               | 可变借用   |

关于所有权请看所有权的章节。 我们再只关心值时不要使用idx相关方法，因为他的性能比直接集合遍历差



### while循环

```
let mut number = 1;
while number != 4 {
    println!("{}", number);
    number += 1;
}
```

和swift类似不需要小括号，但是加上也没问题。



### loop循环

```
let s = ['R', 'U', 'N', 'O', 'O', 'B'];
let mut i = 0;
let location = loop {
    let ch = s[i];
    if ch == 'O' {
        break i;
    }
    i += 1;
};
println!(" \'O\' 的索引为 {}", location);
```

rust中没有do-while循环，取而代之的是loop循环，值得注意的是__break结合loop可以返回一个值__
