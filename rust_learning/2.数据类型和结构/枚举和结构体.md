### 元组枚举或枚举的关联值

如果你现在正在开发一个图书管理系统，你需要描述两种书的不同属性（纸质书有索书号，电子书只有 URL），你可以为枚举类成员添加元组属性描述：

```
#[derive(Debug)]

    Papery(u32), // 纸质书的索引
    Electronic(String), // 电子书地址
}

let book1 = Book1::Electronic("www.baidu.com".to_string());
println!("{:?}， size_of {}", book1, mem::size_of_val(&book1));
```

我们可以在后面追加一个元祖，当然元组内成员数量是不限制的，初始化时按照参数顺序传入即可。使用是使用if let进行匹配，当然几乎所有情况下枚举我们不会使用if let对枚举值进行匹配，但是rust中又没有switch语句，在rust中我们使用match语句来匹配枚举的值，这个在后面会介绍。

对比swift，swift只支持元组枚举，在swift中使用switch或者if case 来匹配关联枚举。学习swift时探索过关联枚举的内存布局，关联枚举实际上是一个联合体，最长的存储单元决定了枚举的存储单元，这一点各个语言机制都是相通的，统称为标签联合体（tagged union）

__通过16进制地址发现，枚举的实质就是联合体，共用一块内存。不书写isize值的占用1个字节， 书写isize值的编译器根据值的范围来确定占用大小，元组枚举或结构体枚举以最大的item占用的内存为准__

### if-let 匹配

```
#[derive(Debug)]
enum Book1 {
```

元组枚举(标签联合体)的匹配很简单， 首先匹配主类型(因为枚举属于联合体，共用一块内存，首先确定解析类型)，如果能匹配则会解析绑定book1中的变量，当然也是有所有权转移的所以这里使用的引用(代码中还对book1做了match匹配)。当然绑定的变量如果不使用可以加 `_` 前缀来规避警告

```
let book2 = Book2::Papery {index: 101};
```

### while let

```
// Vec是动态数组
let mut stack = Vec::new();

// 向数组尾部插入元素
stack.push(1);
stack.push(2);
stack.push(3);

// stack.pop从数组尾部弹出元素
while let Some(top) = stack.pop() {
    println!("{}", top);
}
```

这个例子会打印出 `3`、`2` 接着是 `1`。`pop` 方法取出动态数组的最后一个元素并返回 `Some(value)`，如果动态数组是空的，将返回 `None`，对于 `while` 来说，只要 `pop` 返回 `Some` 就会一直不停的循环。一旦其返回 `None`，`while` 循环停止。我们可以使用 `while let` 来弹出栈中的每一个元素。

### match匹配

上面我们说过了，在其他语言中switch语句是很常见的，但是在rust中丢弃了switch，类似的是match语句，丢弃的原因众说纷纭，公认的有两个

1. switch的break语句很误导人。在C中不写break可能会导致代码逻辑异常，很显然swift也注意到了这一点，在swift中强制每个case隐式携带break。在rust中为了使开发人员脱离原来的思维定式，干脆移除了switch语句使用match匹配来替代

2. switch语句的不可预估性，switch语句匹配模式是单一的，例如：
   ```
   int value = 10;
   switch (value) {
     case 'A':
       // 执行某些操作
       break;
     case 10:
       // 执行另一些操作
       break;
     default:
       // 执行默认操作
       break;
   }
   ```

   这对于一门强类型语言来说是不可取的

match 表达式在 Rust 中具有以下优点：

1. 完整性检查：match 表达式强制要求覆盖所有可能的情况，防止遗漏分支并提供更好的代码完整性。
2. 细粒度的模式匹配：match 表达式可以根据不同的模式进行匹配，包括常量、范围、变量绑定等，提供更灵活的匹配选项。
3. 类型安全：match 表达式在编译时检查变量和模式的类型匹配，避免了类型错误和未定义行为。

我们结合上面定义的枚举看看match语句的具体使用：

```
match book {
    Book::Papery => println!("这是纸质书"),
    Book::Electronic => println!("这是电子书"),
}

match book1 {
    Book1::Papery(_) => println!("这是纸质书 省略编号"),
    Book1::Electronic(address) => println!("此书的地址是 address: {}", address),
}

match book2 {
    Book2::Papery { index } => println!("此书的编号是 index: {}", index),
    Book2::Electronic { address } => println!("此书的地址是 address: {}", address),
}
```

match后面跟着具体的实例，不同类型用 =>分隔开，中间用`,`连接，如果多行语句需要加大括号。当然元组可以省略不需要的参数，表达式也可以支持返回

match语句中想跳过其余匹配使用_即可, 类似其他语言中的default：

```
enum Direction {
    East,
    West,
    North,
    South,
}

let dire = Direction::South;
match dire {
    Direction::East => println!("East"),
    Direction::North | Direction::South => {
        println!("South or North");
    },
    _ => println!("West"),
};
```

我们可以用`|`连接多个值进行匹配，作用类似匹配多个条件中的一个，类似c中caseA caseB caseC共用一个break

来看看 `match` 的通用形式：

```rust
match target {
    模式1 => 表达式1,
    模式2 => {
        语句1;
        语句2;
        表达式2
    },
    _ => 表达式3
}
```

match匹配的模式可以是 ，严格的字面量匹配，类型匹配（枚举），解构匹配， 范围匹配（a..b）等等，而且返回一个值，默认返回（），前提是返回值类型必须一致。

| 模式类型   | 操作符      | 示例                   | 注意                                                 |
| ---------- | ----------- | ---------------------- | ---------------------------------------------------- |
| 字面量     |             | "你好" => {}           |                                                      |
| 多条件语句 | \|          | 1 \| 2 => {}           | 多个条件合并为一个结果，类似c中多个case配合一个break |
| 序列       | ..=         | 1..=5 => {}            | 匹配模式支持闭区间 1..5 这种是不支持的               |
| 枚举       |             |                        | Direction::East => println!("East")                  |
| 额外if条件 | pat if expr | Some(x) if x < 5 => {} | 这里就是matches！宏中使用的方法                      |



更多match规则参考 https://course.rs/basic/match-pattern/match-if-let.html

### matches！

```
let foo = 'f';
assert!(matches!(foo, 'A'..='Z' | 'a'..='z'));

let bar = Some(4);
assert!(matches!(bar, Some(x) if x > 2));
```

我们来看看它的定义

```
macro_rules! matches {
    ($expression:expr, $pattern:pat $(if $guard:expr)? $(,)?) => {
        match $expression {
            $pattern $(if $guard)? => true,
            _ => false
        }
    };
}
```

### Option枚举

在swift中`？`表示可选值，本质上是一个枚举，在swift中可选被定义为

```
enum Optional<T> : NilLiteralConvertible, Reflectable {  
        case None  
        case Some(T)  
        //...
}
```

而在rust中

```
enum Option<T> {
    Some(T),
    None,
}
```

这俩语言不知道谁抄谁的。Option 是 Rust 标准库中的枚举类，这个类用于填补 Rust 不支持 null 引用的空白。如果你想定义一个可以为空值的类，你可以这样：

```
let book3 = Some(Book::Papery);
println!("{:?}", book3);

let book4: Option<Book> = None;
println!("{:?}", book4);
```

在swift中使用可选根本不像一个枚举，使用起来太灵活了，但是在rust中必须按照枚举的形式声明， __请注意book4由于初始化为空，因此必须指明类型__

在swift中想匹配一个可选，必须使用解包，在rust中也是一样的，我们使用上面用到过的两种方式来对book3进行匹配

```
if let Option::Some(book) = book3 {
    println!("book3 is {:?}", book);
}

match book4 {
    Option::Some(book) => println!("book4 is {:?}", book),
    Option::None => println!("book4 is nothing")
}
```

我们看到在rust中使用option还是比较死板的, 由于是rust语言系统支持的语法，当然可以简写

```
let t = Some(64);
match t {
    Some(64) => println!("Yes"),
    _ => println!("No"),
}
```

对比swift比较鸡肋，建议还是写上Option。在rust中匹配case后只能在作用域中使用解析的关联值，这会导致我们的代码嵌套层数过多，对比swift的gruad let语句-- 其可以在解析为空返回，解析有值时将解析值绑定到一个新的变量上，如果在rust中想实现这个效果需要这么做

```
let book5 = Some(Book::Papery);
let b: Book;
if let Option::Some(book) = book5 {
    b = book;
} else {
    return;
} 
println!("b is {:?}", b);
```

这里会发现很奇怪的一点，b声明为let但是在判断内却能被修改，虽然b是let但是未被绑定数据，如果已绑定数据是不允许修改的。 

__回溯: 这里为什么能不初始化？rust在使用一个let变量必须保证其初始化，哪怕你延时初始化也没关系，但是一定要保证有值，这里就是延时初始化b，我们通过return保证b不可变变量一定被初始化才被使用__

### 结构体

Rust 中的结构体（Struct）可以将若干个类型不一定相同的数据捆绑在一起形成整体，结构体的每个成员和其本身都有一个名字

这是一个结构体定义：

```
struct Site {
    domain: String,
    name: String,
    nation: String,
    found: u32
}
```

不能声明实例，结尾不需要 **;** 符号，而且每个字段定义之后用 **,** 分隔。

### 结构体实例

```
let runoob = Site {
    domain: String::from("www.runoob.com"),
    name: String::from("RUNOOB"),
    nation: String::from("China"),
    found: 2013
};
```

有这样一种情况：你想要新建一个结构体的实例，其中大部分属性需要被设置成与现存的一个结构体属性一样，仅需更改其中的一两个字段的值，可以使用结构体更新语法：

```
let site = Site {
    domain: String::from("www.runoob.com"),
    name: String::from("RUNOOB"),
    ..runoob
};
```

注意：**..runoob** 后面不可以有逗号。这种语法不允许一成不变的复制另一个结构体实例，意思就是说至少重新设定一个字段的值才能引用其他实例的值。

### 结构体所有权

**把结构体中具有所有权的字段转移出去后，将无法再访问该字段，但是可以正常访问其它的字段**。

结构体必须掌握字段值所有权，因为结构体失效的时候会释放所有字段。上面例子中都使用的String获取创建对象的所有权，完整的所有权机制后再后面详细学习。

### 结构体内存布局

和swift类似，结构体会被编译器进行字段排序和内存对齐。排序原则根据编译器不同会有所不同。对齐方式是按照最大元素大小对齐(如果最大元素的字节超过8，则使用8字节对齐)，通过这个规则我们很容易推测结构体的真实大小，例如

```
struct Temp {
   a: u64, // 8
   b: String, // 24
   c: u8 // 1
} // 33
```

(33 + 7) >> 3 << 3 = 40  或者 （33 + 7）& ~7 = 40

### 结构体方法

方法（Method）和函数（Function）类似，只不过它是用来操作结构体实例的。

如果你学习过一些面向对象的语言，那你一定很清楚函数一般放在类定义里并在函数中用 this 表示所操作的实例。

Rust 语言不是面向对象的，从它所有权机制的创新可以看出这一点。但是面向对象的珍贵思想可以在 Rust 实现。

结构体方法的第一个参数必须是 &self，不需声明类型，因为 self 不是一种风格而是关键字。

计算一个矩形的面积：

```
struct Rectangle {
    width: u32,
    height: u32,
}
   
impl Rectangle {
    fn area(&self) -> u32 {
        self.width * self.height
    }
}

fn main() {
    let rect1 = Rectangle { width: 30, height: 50 };
    println!("rect1's area is {}", rect1.area());
}
```

__这种添加&self参数的成为结构体方法，这种方法跟实例绑定，必须实例才能调用，对比OC和其他语言就是实例方法。&self属于隐式参数，这里传递self不转移所有权__

### 结构体关联函数

之所以"结构体方法"不叫"结构体函数"是因为"函数"这个名字留给了这种函数：它在 impl 块中却没有 &self 参数。

这种函数不依赖实例，但是使用它需要声明是在哪个 impl 块中的。

一直使用的 **String::from** 函数就是一个"关联函数"。

```
#[derive(Debug)]
struct Rectangle {
    width: u32,
    height: u32,
}

impl Rectangle {
    fn create(width: u32, height: u32) -> Rectangle {
        Rectangle { width, height }
    }
}

fn main() {
    let rect = Rectangle::create(30, 50);
    println!("{:?}", rect);
}
```

__这种不添加&self参数的称为结构体关联函数，这种方法跟实例无关，对比OC和其他语言就是类方法或静态方法__
