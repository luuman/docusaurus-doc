### 函数定义

```
fn <函数名> ( <参数> ) <函数体>

fn another_function(x: i32, y: i32) -> i32 {
    println!("x 的值为 : {}", x);
    println!("y 的值为 : {}", y);
    return 0;
}
```

我们可以看到和swift一模一样，只是不具备swift外部参数的定义，在swift和oc中参数都有类似描述或函数名称，这样更利于理解代码。

### 函数的参数

参数描述 值 引用 指针， 不定长参数，可变参列表等

### 函数的返回值

在rust下函数更广泛，一个代码块我们也可以称为匿名函数，正常在函数中使用return返回一个结果，在匿名代码块中更随意

```
let y = {
    let x = 3;
    x + 1
};
```

上面代码中我们能清晰看到最后一行没有__分号__, 分号确实会被认定为返回值，这种代码块的形式返回一个值称为__函数体表达式__, 在里面不可以写return，而且如果需要函数体的值的话最后一行必须省略分号。

```
fn five() -> i32 {
    5
}
```

常规函数我们也可以不写return，这个和swift是一致的，如果函数体比较复杂建议还是写上return

### 函数作为参数

在 Rust 下，函数是一等公民，可以作为参数或者返回值。

```
// 两数之和
fn add(a: i32, b: i32) -> i32 {
    a + b
}

// 两数之积
fn multiply(a: i32, b: i32) -> i32 {
    a * b
}

// 传入参数和操作函数求值
fn result(a: i32, b: i32, expr: fn(i32, i32) -> i32) -> i32 {
    expr(a, b)
}

// 函数作为参数
let sum_result = result(1, 2, add);
println!("sum_result = {}", sum_result);
let multiply_result = result(3, 4, multiply);
println!("product_result = {}", multiply_result);
```

result函数传入两个值和一个函数参数，在内部利用传入的函数参数计算两个值的结果， 这里我们实现了两数之和和两数之积

### 函数作为返回值

```
enum Operator {
    Add,
    Multiply,
}

fn get_operation(opt: Operator) -> fn(i32, i32) -> i32 {
    match opt {
        Operator::Add => add,
        Operator::Multiply => multiply,
    }
}

// 函数作为返回值
let sum_result1 = result(1, 2, get_operation(Operator::Add));
println!("sum_result1 = {}", sum_result1);
let multiply_result1 = result(3, 4, get_operation(Operator::Multiply));
println!("product_result1 = {}", multiply_result1);
```

我们同过枚举间接返回操作函数

### 构造异常函数

当用 `!` 作函数返回类型的时候，表示该函数永不返回( diverge function )，特别的，这种语法往往用做会导致程序崩溃的函数：

```rust
fn dead_end() -> ! {
  panic!("你已经到了穷途末路，崩溃吧！");
}
```
