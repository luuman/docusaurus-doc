### 配置和安装

UNIX系统下可以直接按照如下命令安装rust

```
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
```

安装完成后推荐的ide是我们熟知的 `vscode`

vs商店中提供了很多rust插件，这有利于我们更好的编写rust

1. `rust-analyzer` 它会实时编译和分析你的 Rust 代码，提示代码中的错误，并对类型进行标注。也可以使用官方的 `rust for vsc`
2. `rust syntax` 为代码提供语法高亮
3. `crates` 帮助你分析当前项目的依赖是否是最新的版本
4. `better toml` 现已更名为 `Even Better TOML` Rust 使用 toml 做项目的配置管理。better toml 可以帮你语法高亮，并展示 toml 文件中的错误
5. `rust test lens` 可以帮你快速运行某个 Rust 测试
6. `Tabnine` 基于 AI 的自动补全，可以帮助你更快地撰写代码。 安装后注册即可，会有个聊天窗口类似GPT
7. `Error Lens` 能让报错更清晰更直观

这些插件的安装方式点击vs最左侧的插件按钮，然后再商店搜索安装即可。到此就可以编写rust项目了

### cargo命令

cargo 一个管理工具，用来做项目生成，编译，运行，测试，以及代码格式化等等操作。这里会介绍一些常用命令，在后续学习中也会不断补充这里的命令

1. 创建项目 `cargo new <path>`

   我们一般现cd到某个目录，然后执行`cargo new <Target—Name>`

2. 运行项目 `cargo run`

   这一步需要在包含toml配置的目录执行，他会加载toml中的依赖项，并且编译项目运行
