# Claude Code 完全指南

Claude Code 是由 Anthropic 开发的**系统级 AI Agent**，它不只是一个代码补全工具，而是一个能够深度介入你开发流程的智能协作者。它可以读写文件、执行命令、调用外部工具、与多个子代理协作，完成从需求分析到代码部署的完整工作流。

---

## 核心特性

### 全功能系统访问

Claude Code 拥有对本地系统的完整访问权限，可以直接操作文件系统、执行 Shell 命令、调用 CLI 工具，无需中间层转发。这意味着它可以像一个真正的开发者一样工作，而不仅仅是给出建议。

### 200K Token 超大上下文

单次会话支持高达 200,000 token 的上下文窗口，足以容纳：
- 整个中型项目的核心代码
- 完整的架构文档与需求规格
- 跨文件的复杂依赖关系分析

这使得 Claude Code 能够在不丢失上下文的情况下处理真实世界的大型任务。

### 高度可扩展性

通过多种扩展机制，Claude Code 可以适配任意技术栈和工作流：

| 扩展机制 | 作用 |
|---------|------|
| **Skills** | 自定义斜杠命令，封装常用工作流 |
| **Hooks** | 在特定生命周期事件中注入自定义逻辑 |
| **Plugins** | 可复用的功能模块，团队共享 |
| **MCP Servers** | 集成外部服务与数据源 |
| **Subagents** | 并行多代理任务分发与协作 |

### 多代理协作

Claude Code 支持 Orchestrator-Subagent 架构。主代理可以将复杂任务拆解，并行派发给多个子代理执行，最后汇总结果。这种模式特别适合：
- 大型代码库的并行分析
- 多模块同步重构
- 跨服务的集成测试生成

### 自然交互

支持纯自然语言驱动开发。你可以直接描述需求，Claude Code 会自动规划步骤、选择工具、执行操作，并在关键节点向你确认。

## 能力清单

在开始使用前，了解 Claude Code 能做什么与不能做什么，有助于你制定合理的使用策略。

### 擅长的任务

- [x] 读取、编写、重构任意格式的文件
- [x] 执行 Shell 命令并分析输出结果
- [x] 跨多个文件追踪复杂依赖关系
- [x] 理解并生成中文注释与文档
- [x] 自动化重复性开发任务（生成测试、格式化、迁移脚本）
- [x] 结合 MCP 访问数据库、API、浏览器等外部资源
- [x] 通过 Subagents 并行处理大型任务
- [x] 在会话中持续追踪上下文，无需反复说明背景

### 需要注意的边界

- [ ] 不会主动推送到远程仓库（除非你明确要求）
- [ ] 危险操作（删除文件、覆盖数据）会默认请求确认
- [ ] 网络访问能力取决于 MCP Server 的配置
- [ ] 对话上下文不跨会话持久化（依赖 CLAUDE.md 传递项目知识）

:::tip 建议的起点
如果你是第一次使用 Claude Code，建议从 [快速开始](./getting-started.md) 章节开始，完成安装和基础配置后，再根据实际需求探索 Skills、Hooks 等高级特性。
:::

:::info 模型选择
Claude Code 支持接入多种模型，包括 Anthropic 官方模型和国内主流大模型（GLM、Kimi、DeepSeek、通义千问）。国内用户无需科学上网即可完整使用所有功能，具体配置见 [快速开始 - 模型配置](./getting-started.md#模型配置) 章节。
:::
