# 杀毒软件误报申诉

> Windows 发版后可能触发杀毒软件误报,本文档记录各平台的申诉渠道和操作方法。

## 检测渠道

- [VirusTotal](https://www.virustotal.com/) — 发布前建议做一次全量检测

## 360 杀毒申诉

### 国内版

- 地址: [360 软件开放平台](https://open.360.cn)
- 需附上误报截图,说明程序功能(修改 URL 协议、开机启动项等)

### 国际版

- 地址: [360 Total Security 误报提交](https://www.360totalsecurity.com/en/help/false-positive/)

### 常见误报提示

- 修改 URL 协议关联
- 启动提示修改文件
- 卸载程序提示病毒
- 修改开机启动项
- SDK 程序报木马

## 腾讯电脑管家申诉

### 企业快速通道

通过 Matrx 项目控制台申诉通道提交,建议以企业用户身份提交。

### 个人申诉通道

- 地址: [腾讯电脑管家误报申诉](https://guanjia.qq.com/online_server/online_server_new.html)
- 处理速度较慢

## VirusTotal 误报申诉

1. 登录 [VirusTotal](https://www.virustotal.com/)
2. 点击 "Ask technical support" 提交误报说明

## Bitdefender 申诉

- [Bitdefender 误报申诉](https://www.bitdefender.com/consumer/support/answer/29358/)

## 建议

- 发布版本前使用 VirusTotal 做全量检测
- 对所有误报截图统一保留归档
- 尽量以企业身份申诉,提高处理效率
