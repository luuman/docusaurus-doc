# 项目整体架构

## 概述

Matrx Windows 是一个典型的 Electron 多进程架构应用，采用 **主进程 + 多渲染进程 + SDK 进程** 的三层架构设计。

## 核心设计理念

### 1. 进程分离

Electron 应用天然分为主进程和渲染进程，本项目充分利用这一特性：

| 进程类型 | 职责 | 访问能力 |
|---------|------|---------|
| 主进程 | 窗口管理、系统交互、数据持久化 | Node.js 完整能力 |
| 渲染进程 | UI 展示、用户交互 | 受限的 Node.js 能力 |
| SDK 进程 | 音视频处理 | 独立运行 |

### 2. 多窗口架构

项目采用多页面应用（MPA）模式，每个功能窗口独立运行：

```javascript
// vue.config.js 中的 pages 配置
pages: {
  index: 'src/main.js',           // 主窗口
  start: 'renderer/start/main.js', // 启动页
  screenshot: 'renderer/screenshot/main.js', // 截图
  // ... 共 26 个页面
}
```

### 3. 单实例锁

确保同一时间只有一个应用实例运行：

```javascript
// src/background.js
const gotTheLock = app.requestSingleInstanceLock();
if (!gotTheLock) {
  app.quit();
}
```

### 4. 协议处理

支持自定义协议 `matrxmeeting://`，用于深度链接：

```javascript
app.setAsDefaultProtocolClient('matrxmeeting');
```

## 安全设计

### 1. 上下文隔离

```javascript
// 窗口创建时
webPreferences: {
  contextIsolation: true,      // 上下文隔离
  enableRemoteModule: false,   // 禁用 remote 模块
  nodeIntegration: false       // 禁用 Node 集成
}
```

### 2. 预加载脚本

通过 `preload.js` 安全暴露必要的 API：

```javascript
// src/preload.js
const { contextBridge, ipcRenderer } = require('electron');

contextBridge.exposeInMainWorld('electron', {
  ipcRenderer: {
    send: (channel, ...args) => ipcRenderer.send(channel, ...args),
    on: (channel, func) => ipcRenderer.on(channel, (event, ...args) => func(...args)),
    invoke: (channel, ...args) => ipcRenderer.invoke(channel, ...args)
  }
});
```

### 3. 数据加密

- **数据库加密**: 使用 SQLCipher 加密本地数据库
- **配置加密**: 生产环境下 electron-store 数据加密
- **日志加密**: 生产环境下日志文件加密
