# 数据库整体架构 | Matrx

## 数据库整体架构

## 使用 SQLCipher 进行数据库管理 | luuman/matrx-windows | Zread

matrx-windows 应用程序使用 SQLCipher 实现了一个精密的加密数据库管理系统，为用户数据、消息和应用状态提供安全的本地存储。该系统通过优化的数据库操作和连接管理，确保数据机密性的同时保持高性能。

## SQLCipher 集成架构[](#sqlcipher-%E9%9B%86%E6%88%90%E6%9E%B6%E6%9E%84)[​](#sqlcipher-集成架构 "sqlcipher-集成架构的直接链接")

数据库层围绕 SQLCipher 构建，这是一个为数据库文件提供透明 256 位 AES 加密的 SQLite 扩展。集成采用了多层架构：

应用层

SQL API 层

SQLite 工具层

数据库连接层

SQLCipher 引擎

加密数据库文件

安全管理器

版本管理

连接池

核心连接管理由 `logicDBConnect.js` 处理，它使用用户特定的加密密钥建立加密数据库连接 \[src/utils/logicDBConnect.js#L8-L64\]。每个用户空间维护自己的加密数据库文件，路径结构为 `{configDir}/{vuid}/{spaceId}/{vuid}.{spaceId}.db.db`。

## 数据库连接与安全[](#%E6%95%B0%E6%8D%AE%E5%BA%93%E8%BF%9E%E6%8E%A5%E4%B8%8E%E5%AE%89%E5%85%A8)[​](#数据库连接与安全 "数据库连接与安全的直接链接")

### 加密配置[](#%E5%8A%A0%E5%AF%86%E9%85%8D%E7%BD%AE)[​](#加密配置 "加密配置的直接链接")

SQLCipher 配置了特定的安全参数，以平衡安全性和性能：

- **密码兼容性**：设置为版本 3 以保持向后兼容 \[src/utils/logicDBConnect.js#L62\]
- **密钥派生**：使用 10,000 次 PBKDF2 迭代进行密钥强化 \[src/utils/logicDBConnect.js#L65\]
- **数据库密码**：从 SDK 安全获取并缓存在内存中 \[src/utils/logicDBConnect.js#L18-L32\]

数据库密码永远不会持久存储在磁盘上。它们通过 IPC 通信从 SDK 获取，仅在应用程序会话期间缓存在内存中。

### 连接管理[](#%E8%BF%9E%E6%8E%A5%E7%AE%A1%E7%90%86)[​](#连接管理 "连接管理的直接链接")

系统通过 `multipleDBInsMange.js` 实现了精密的连接池机制，为每个用户空间组合维护独立的数据库实例 \[src/utils/multipleDBInsMange.js#L4-L16\]。这确保了不同用户上下文之间的隔离，同时优化了连接重用。

## 数据库架构与版本控制[](#%E6%95%B0%E6%8D%AE%E5%BA%93%E6%9E%B6%E6%9E%84%E4%B8%8E%E7%89%88%E6%9C%AC%E6%8E%A7%E5%88%B6)[​](#数据库架构与版本控制 "数据库架构与版本控制的直接链接")

### 初始架构结构[](#%E5%88%9D%E5%A7%8B%E6%9E%B6%E6%9E%84%E7%BB%93%E6%9E%84)[​](#初始架构结构 "初始架构结构的直接链接")

数据库架构通过 `src/sql/init/` 目录中的版本控制迁移脚本进行初始化。初始架构 (v1) 定义了几个核心表：

| 表名         | 用途                     | 主要功能                        |
| ------------ | ------------------------ | ------------------------------- |
| `message`    | 存储聊天消息和文件传输   | FTS 索引、UUID 唯一性、内容加密 |
| `peer`       | 管理联系人和群组信息     | 多类型关系（个人/群组/好友）    |
| `file`       | 跟踪文件元数据和传输状态 | 下载进度跟踪                    |
| `IndexTable` | 全文搜索索引             | FTS4 虚拟表用于内容搜索         |
| `metaTable`  | 应用程序元数据           | 带时间戳的业务项跟踪            |

\[src/sql/init/v1.js#L1-L144\]

## 数据访问层[](#%E6%95%B0%E6%8D%AE%E8%AE%BF%E9%97%AE%E5%B1%82)[​](#数据访问层 "数据访问层的直接链接")

### SQL API 抽象[](#sql-api-%E6%8A%BD%E8%B1%A1)[​](#sql-api-抽象 "sql-api-抽象的直接链接")

应用程序通过 `sqlApi/index.js` 提供高级 SQL API，将原始 SQL 操作抽象为可重用函数：

- **查询操作**：`selectAll()`、`selectAllNum()`、`selectObj()`
- **修改操作**：`updateAll()`、`addInsertAll()`、`deleteAll()`
- **参数化查询**：所有操作都使用参数绑定以防止 SQL 注入

\[src/sqlApi/index.js#L1-L88\]

### SQLite 工具函数[](#sqlite-%E5%B7%A5%E5%85%B7%E5%87%BD%E6%95%B0)[​](#sqlite-工具函数 "sqlite-工具函数的直接链接")

`SqliteUtil.js` 模块提供带有错误处理和事务支持的低级数据库操作 \[src/utils/SqliteUtil.js#L44-L414\]。主要功能包括：

- **批处理操作**：基于事务的批量插入和更新以提高性能
- **全文搜索集成**：与 FTS 索引自动同步
- **错误处理**：全面的错误日志记录和恢复机制

## 性能优化[](#%E6%80%A7%E8%83%BD%E4%BC%98%E5%8C%96)[​](#性能优化 "性能优化的直接链接")

### 数据库配置[](#%E6%95%B0%E6%8D%AE%E5%BA%93%E9%85%8D%E7%BD%AE)[​](#数据库配置 "数据库配置的直接链接")

SQLCipher 数据库为桌面应用程序环境进行了性能优化配置：

- **WAL 模式**：启用并发读写 \[src/utils/logicDBConnect.js#L68\]
- **同步模式**：设置为 NORMAL 以平衡持久性和性能 \[src/utils/logicDBConnect.js#L70\]
- **忙超时**：6 秒超时用于处理锁争用 \[src/utils/logicDBConnect.js#L66\]

### 索引策略[](#%E7%B4%A2%E5%BC%95%E7%AD%96%E7%95%A5)[​](#索引策略 "索引策略的直接链接")

架构包含对频繁查询列的全面索引：

- 按对话、UUID 和文档 ID 的消息索引
- 按各种关系属性的联系人索引
- 通过 FTS4 虚拟表实现全文搜索功能

批处理操作使用预处理语句和事务来最小化数据库往返次数，显著提高批量数据操作的性能。

## 安全考虑[](#%E5%AE%89%E5%85%A8%E8%80%83%E8%99%91)[​](#安全考虑 "安全考虑的直接链接")

### 数据加密[](#%E6%95%B0%E6%8D%AE%E5%8A%A0%E5%AF%86)[​](#数据加密 "数据加密的直接链接")

所有数据库文件都使用 SQLCipher 的 AES-256 加密，确保即使数据库文件被泄露，没有正确的加密密钥数据仍然无法访问。

### 访问控制[](#%E8%AE%BF%E9%97%AE%E6%8E%A7%E5%88%B6)[​](#访问控制 "访问控制的直接链接")

系统通过以下方式实现多租户隔离：

- **基于空间的分离**：每个用户空间维护独立的数据库
- **主机 ID 验证**：所有操作都包含主机 ID 验证
- **参数绑定**：防止 SQL 注入攻击

## 集成点[](#%E9%9B%86%E6%88%90%E7%82%B9)[​](#集成点 "集成点的直接链接")

数据库层与多个其他应用程序组件集成：

- **IPC 通信**：通过安全 IPC 通道检索数据库密码
- **文件系统**：在用户目录中存储加密数据库文件
- **搜索系统**：与全文搜索索引实时同步
- **安全模块**：与应用程序范围的加密密钥管理集成

这个全面的数据库管理系统为安全、高性能的本地数据存储提供了基础，同时为未来的功能开发和架构演进保持了灵活性。
