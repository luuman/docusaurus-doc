# Windows 发版误报杀毒软件申诉说明

**负责人**：yongmao.tian  
**最后更新**：2023 年 2 月 1 日  
**查看人数**：3

## 一、病毒检测常用渠道

- [VirusTotal](https://www.virustotal.com/)
- 360 杀毒
- 腾讯电脑管家

统一申诉 QQ：

- `292601191`
- `31240879*`

## 二、360 杀毒申诉渠道

### 1. 360 国内版误报申诉

- **地址**：[360 软件开放平台](https://open.360.cn)
- **申诉截图**：需附上提示误报的截图，说明程序功能如修改 URL 协议、开机启动项等。

### 2. 360 国际版申诉

- **地址**：[误报软件/可疑文件上传 | 360 Total Security](https://www.360totalsecurity.com/en/help/false-positive/)
- **申诉邮箱**：`292601191@qq.com`
- **常见误报提示**：
  - 修改 URL 协议关联
  - 启动提示修改文件
  - 卸载程序提示病毒
  - 修改开机启动项
  - SDK 程序报木马

## 三、腾讯电脑管家申诉

### 1. 企业快速通道

- 通过 **Matrx 项目控制台申诉通道** 提交，建议作为企业用户提交。

### 2. 个人申诉通道（处理速度较慢）

- [腾讯电脑管家误报申诉地址](https://guanjia.qq.com/online_server/online_server_new.html)
- **申诉说明**：同样建议说明软件会修改协议关联但无病毒行为。

## 四、VirusTotal 误报申诉

- 登录 [VirusTotal 官网](https://www.virustotal.com/)
- 点击 “Ask technical support” 提交误报说明。

## 五、其他杀毒软件

以下厂商暂不处理申诉：

- 金山毒霸
- 瑞星
- 火绒

若需申诉 Bitdefender：

- [Bitdefender 官方误报申诉链接](https://www.bitdefender.com/consumer/support/answer/29358/)

## 📌 小贴士

- 发布版本前建议使用 VirusTotal 做一次全量检测；
- 对所有误报截图统一保留归档，便于日后版本提交参考；
- 尽量以企业身份申诉，提高处理效率。
