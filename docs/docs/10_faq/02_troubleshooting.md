# 故障排查大全 Troubleshooting Guide

本文件详细梳理项目各模块在实际安装、运行、升级、使用等过程中可能遇到的故障类型，并针对每一类现象列出典型故障原因，便于快速定位与解决问题。

---

## 一、安装与启动故障

### 1. 安装失败

- **依赖未安装/版本不符**
  - Node、npm、pnpm/yarn 版本低/高于要求
  - Python（如涉及 node-gyp）、VS BuildTools 缺失
  - 系统架构不兼容（如 32 位/ARM）
- **网络问题**
  - 依赖包下载超时，网络被墙
  - npm registry 被拦截或限速
- **权限问题**
  - 无法写入 node_modules、锁文件目录权限不足
  - Windows 上以非管理员身份安装
- **磁盘空间不足**

### 2. 启动失败

- **环境变量缺失/错误**
  - NODE_ENV、配置文件路径未设置或拼写错误
- **端口被占用**
  - 默认端口被其他程序占用
- **配置文件缺失/格式错误**
  - config.js、.env 文件未初始化或语法错误
- **数据库初始化失败**
  - SQLCipher 密钥不正确、数据库文件损坏、目录无写权限
- **依赖包损坏**
  - node_modules 被误删或不完整

---

## 二、数据库相关故障

### 1. 数据库连接异常

- **密钥错误/加密参数不匹配**
  - PRAGMA key 配置与实际密钥不一致
  - KDF 迭代次数配置错误
- **数据库文件损坏**
  - 强制关闭、磁盘损坏导致数据库不可读
- **路径错误**
  - 数据库路径拼写错误或目录不存在

### 2. 数据库升级/迁移异常

- **版本号不匹配**
  - dbVersion/config 中的版本未同步
- **升级脚本执行失败**
  - SQL 语法错误、字段冲突
- **权限不足**
  - 无法写入数据库目录或执行 ALTER 语句

### 3. 数据丢失/异常

- **未做备份**
  - 手动升级/误操作导致历史数据丢失
- **误删除或覆盖**
  - 自动脚本、初始化流程误删历史文件
- **密钥丢失**
  - 数据库加密密钥遗失，数据不可恢复

---

## 三、IM 通信与消息故障

### 1. 消息收发异常

- **长连接断开/重连失败**
  - 网络波动，服务端限制，防火墙拦截
- **ACK 队列堵塞或丢失**
  - 进程异常、内存不足导致 ACK 消息未及时处理
- **消息重复/乱序**
  - 唯一 ID 生成冲突，去重逻辑失效
- **消息丢失**
  - 断网/重连时本地消息未同步到服务器
- **离线消息未补全**
  - 本地缓存损坏，补全逻辑异常

### 2. 群聊/空间切换异常

- **空间 ID 冲突或丢失**
  - 数据库空间表未同步
- **权限不足**
  - 用户无权访问目标空间或群组
- **组织架构数据异常**
  - 组织表结构变更导致数据无法正常加载

---

## 四、桌面客户端故障（Electron）

### 1. 窗口无法打开/多窗口异常

- **主进程/渲染进程崩溃**
  - IPC 通信异常，内存泄漏
- **窗口参数错误**
  - 创建窗口时传参不合法
- **系统限制**
  - Windows/macOS 系统权限/多窗口策略限制

### 2. 系统托盘/桌面通知失效

- **权限限制**
  - 用户操作系统关闭了通知权限
- **Electron API 兼容性问题**
  - Electron 版本升级导致 API 变更

---

## 五、打包/升级相关故障

### 1. 打包失败

- **资源文件缺失**
  - 图标、dll、加密资源未找到
- **脚本语法错误**
  - NSIS/打包脚本拼写错误
- **签名失败**
  - 未配置证书或权限不足

### 2. 升级异常

- **数据迁移未完成**
  - 升级脚本未覆盖所有表
- **配置未同步**
  - 新版配置未自动迁移

---

## 六、安全与加密相关故障

### 1. 数据库/消息体解密失败

- **密钥错误或丢失**
- **加密算法升级不兼容**
- **PBKDF2 参数变更导致解密失败**

### 2. 权限/空间隔离异常

- **权限表未同步**
- **空间隔离逻辑失效**
- **误操作导致权限丢失**

---

## 七、性能与监控相关故障

### 1. 性能瓶颈

- **数据库锁冲突/死锁**
- **消息队列堵塞，CPU/内存占用高**
- **前端 UI 卡顿，事件处理慢**

### 2. 日志与监控异常

- **Sentry/SonarQube 未采集到异常**
- **日志写入失败，文件权限/磁盘空间不足**

---

## 八、常见排查方法

- 查看 logs/ 目录，定位主进程/渲染进程/数据库/IM 通信日志
- 使用 SQLite/SQLCipher 工具校验数据库完整性
- 端口、网络检测：`netstat`、`ping`、`wireshark`
- 配置校验：对比 .env、config.js、数据库路径
- 权限检测：操作系统、目录、网络、数据库文件权限
- 自动化测试/单元测试覆盖率分析

---

## 九、补充建议

- 发生故障时，建议收集：详细报错日志、配置文件、数据库版本、操作系统版本、复现步骤，提交至 issue 或 support 邮箱。
- 每次升级/迁移前，务必做好数据备份。

---

如有新的故障类型或典型案例，请补充至本文件以便团队共享与持续完善。
