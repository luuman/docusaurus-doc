# Start with AI

You can also use Brainboard AI to get started quickly with a prompt:

* Click on the `New architecture` button in the top left part.

<figure><img src="https://2733077811-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F7YhVIZuz5Brv8kisTlFL%2Fuploads%2FaPXZK2uVSKpnIXO3Tw09%2Ffast-track-new-architecture.png?alt=media&#x26;token=2216ffea-1a41-46a5-8b5e-353162e8b57a" alt=""><figcaption><p>Create new architecture</p></figcaption></figure>

* Select `Create using AI` option.

<figure><img src="https://2733077811-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F7YhVIZuz5Brv8kisTlFL%2Fuploads%2FpRQH1oI7t4Ttmy0zwK9o%2Fstart-with-ai.png?alt=media&#x26;token=e056f7c5-e530-4756-83cc-15da30607466" alt=""><figcaption><p>Start with AI option</p></figcaption></figure>

This will give you a text area where you can type your prompt text:

<figure><img src="https://2733077811-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F7YhVIZuz5Brv8kisTlFL%2Fuploads%2FrLDELh7ZcGThVQZTrVn8%2Fstart-with-ai-prompt.png?alt=media&#x26;token=476bd4f7-9ae4-4956-987a-793070e7bde1" alt=""><figcaption><p>AI prompt</p></figcaption></figure>

Brainboard processes your prompt and creates an architecture, you can give it a name as it is ready to be used:

<figure><img src="https://2733077811-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F7YhVIZuz5Brv8kisTlFL%2Fuploads%2FRcQXqqS6BufUOWAd2TKu%2Fstart-with-ai-pre-architecture.png?alt=media&#x26;token=bd484cdb-5ed0-4ff0-888b-bb77f710fa4a" alt=""><figcaption><p>Naming architecture</p></figcaption></figure>

Once the architecture is generated, you'll have the design with the Terraform code generated
