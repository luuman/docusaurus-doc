# Start with a template

One of the fastest ways to start with Brainboard, is to start with a template:

* Click on the `New architecture` button in the top left part.

<figure><img src="https://2733077811-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F7YhVIZuz5Brv8kisTlFL%2Fuploads%2FaPXZK2uVSKpnIXO3Tw09%2Ffast-track-new-architecture.png?alt=media&#x26;token=2216ffea-1a41-46a5-8b5e-353162e8b57a" alt=""><figcaption><p>Create new architecture</p></figcaption></figure>

* Select `From a template` option.

<figure><img src="https://2733077811-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F7YhVIZuz5Brv8kisTlFL%2Fuploads%2FHmsLHpTOVOlX1sK4kE0v%2Fstart-with-template.png?alt=media&#x26;token=1fe5f648-43fd-4c29-ba04-f69bd2f6e858" alt=""><figcaption><p>Start from template option</p></figcaption></figure>

It will open the template catalog where you can search for your use case, For e.g. `landing zone`, `kubernetes`, `security`... or select your preferred cloud provider to only see the templates  of this specific provider:

<figure><img src="https://2733077811-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F7YhVIZuz5Brv8kisTlFL%2Fuploads%2FrI1v7tZGND8xeXSvaNLu%2FCleanShot%202024-09-27%20at%2009.28.39.png?alt=media&#x26;token=75036982-4921-4717-8ee2-5c7213dc1c1b" alt=""><figcaption><p>Templates catalog</p></figcaption></figure>

{% hint style="info" %}
There are 2 types of templates: **public** and **private.**\
You can convert any architecture created into a template. Which allows you to build your internal library of templates.
{% endhint %}
